1. Credential Security

Argon2id hashing is configured with salt generation and memory hardness. Plaintext passwords are never persisted to disk, memory dumps, or log files.

hasher.hash(password)
# Output: $argon2id$v=19$m=65536...
2. Generic Error Responses

Authentication failure returns an identical error message whether the username exists or not. Nonexistent lookups run constant-time dummy verification.

"Invalid username or password."
# HTTP Status: 401 Unauthorized
3. Abuse & Brute-Force Defense

Flask-Limiter intercepts automated credential stuffing attacks, triggering an HTTP 429 Too Many Requests response once threshold is breached.

@limiter.limit("5 per minute")
# HTTP Status: 429 Too Many Requests
